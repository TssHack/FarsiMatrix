## 🎯 معرفی پروژه

پروژه **فارسی ماتریکس (FarsiMatrix)** در نسخه جدید خود از یک REST API متکی به دیتابیس ابری هزینه‌بر، به یک **وب‌اپلیکیشن جامع، مدرن و کاملاً محلی (Local-first)** تبدیل شده است. در معماری جدید:
* نیازی به پرداخت هزینه‌های گزاف ماهانه دیتابیس‌های ابری (مانند Supabase یا AWS) نیست.
* برنامه به صورت **PWA (Progressive Web App)** قابل نصب روی موبایل (اندروید، iOS) و کامپیوتر (ویندوز، مک، لینوکس) است و ۱۰۰٪ آفلاین کار می‌کند.
* به جای دیکشنری ساده، یک **محیط یادگیری تعاملی با جعبه لایتنر ۵ مرحله‌ای و آزمون‌های هوشمند** در اختیار کاربر قرار دارد.

## ✨ ویژگی‌های برجسته

### 🎨 ۱. طراحی بر پایه Google Material Design 3 (Material You)
* رعایت دقیق توکن‌های رسمی M3 شامل لایه‌های رنگی تونال (`primary`, `primary-container`, `surface-container-low`, `surface-container-high` و...).
* **تم دوگانه روز و شب (Dark & Light Mode)** با پالت رنگی چشم‌نواز Teal/Cyan و سطوح پاستلی نرم.
* طراحی واکنش‌گرا و سازگار با انواع نمایشگرها (از گوشی‌های ۳۶۰ پیکسلی تا مانیتورهای عریض).
* تایپوگرافی ویژه فارسی با فونت **وزیرمتن (Vazirmatn)** در کنار تایپ‌فیس انگلیسی خوانا.

### 📚 ۲. دسته‌بندی در ۵۱ سرفصل تخصصی (بیش از ۲۵۰,۰۰۰ لغت)
* **فناوری و مهندسی کامپیوتر:** کامپیوتر و انفورماتیک، الگوریتم‌ها و ساختمان داده، فناوری اطلاعات (IT)، اینترنت و وب، برنامه‌نویسی و ویژوال بیسیک، گرافیک رایانه‌ای، دامنه‌ها، خطاهای مودم، الکترونیک ۱، ۲ و ۳.
* **آموزش زبان و مکالمه:** کلمات ضروری ۱ و ۲ (آزمون‌های آیلتس، تافل و کنکور)، اصطلاحات و ضرب‌المثل‌ها ۱، ۲ و ۳، اصطلاحات چت و اینترنت (Chat Slang)، اصطلاحات تمثیلی و نام‌های متداول.
* **کسب‌وکار و مدیریت:** مدیریت و رهبری ۱ و ۲، حسابداری و مالی ۱، ۲ و ۳ (مالی، حسابرسی و بانکی)، حقوق و علوم قضایی.
* **علوم پایه و پزشکی:** ریاضیات، آمار و احتمالات ۱ و ۲، زیست‌شناسی، نجوم و کیهان‌شناسی، علوم پایه ۱ و ۲ (شیمی)، دندانپزشکی، گیاهان دارویی و فوبیاها.
* **فنی و مهندسی:** مهندسی شیمی، مهندسی صنایع ۱ و ۲، هوانوردی و صنایع هوایی، مهندسی نفت ۱ و ۲ (حفاری و پالایش)، مهندسی پلیمر، نساجی، مکانیک خاک، زمین‌شناسی و هیدروژئولوژی.
* **هنر و سینما:** سینما و فیلم ۱، ۲ و ۳.

### 🗂️ ۳. فلش‌کارت سه‌بعدی و سیستم جعبه لایتنر (Spaced Repetition)
* کارت تعاملی با انیمیشن چرخش ۳D و فیزیک طبیعی.
* **موتور تلفظ صوتی بلادرنگ (Web Speech API):** تلفظ دقیق لغات بدون اینترنت و بدون کوچک‌ترین هزینه سرور.
* ارزیابی سه مرحله‌ای یادگیری:
  - 🔴 **سخت / بلد نبودم (کلید ۱)** ➔ بازگشت به جعبه ۱ برای مرور سریع.
  - 🟡 **متوسط / شک داشتم (کلید ۲)** ➔ ماندن در بازه زمانی فعلی.
  - 🟢 **ساده / مسلط شدم (کلید ۳)** ➔ صعود به جعبه‌های بالاتر لایتنر.
* پشتیبانی کامل از کلیدهای میانبر: `Space` (چرخش کارت)، `1`، `2`، `3` (امتیازدهی)، `S` (تلفظ صوتی)، کلیدهای جهت‌نما (کارت بعدی/قبلی).

### 🎯 ۴. آزمون و تست چهارگزینه‌ای هوشمند
* تولید کوئیزهای پویا در دو حالت: **انگلیسی به فارسی** یا **فارسی به انگلیسی**.
* انتخاب تعداد سوالات (۱۰، ۱۵، ۲۰ یا ۳۰ سوال).
* پاسخ‌های انحرافی هوشمند از همان سرفصل آموزشی.
* فیدبک بصری فوری و انیمیشن جشن Confetti در پایان آزمون.
* مرور سوالات اشتباه و امکان تمرین دوباره آن‌ها در فلش‌کارت.

### 📱 ۵. اپلیکیشن پیش‌رونده (PWA) و ذخیره‌سازی محلی
* قابلیت نصب مستقیم بدون نیاز به اپ‌استور روی تلفن‌های همراه و دسکتاپ.
* حفظ ۱۰۰٪ حریم خصوصی: تمام اطلاعات یادگیری، استریک روزانه و لغات ستاره‌دار در حافظه دستگاه خود کاربر نگهداری می‌شوند.
* امکان خروجی گرفتن فایل پشتیبان (Export JSON) و بازیابی اطلاعات (Import JSON).

## 🏗️ معماری بدون هزینه دیتابیس (Zero DB Cost)

```
┌────────────────────────────────────────────────────────┐
│                   کلاینت فارسی ماتریکس                 │
│         (Next.js 16 + Tailwind CSS + Material 3)       │
└───────────────────────────┬────────────────────────────┘
                            │
            ┌───────────────┴───────────────┐
            ▼                               ▼
┌─────────────────────────┐     ┌────────────────────────┐
│     داده‌های خرد شده     │     │      حافظه محلی کاربر   │
│  (/public/data/groups/) │     │ (IndexedDB / LocalStg) │
│ • ۵۱ فایل سرفصل مستقل   │     │ • مراحل جعبه لایتنر    │
│ • حجم سبک (~۵۰ کیلوبایت)│     │ • لغات نشان‌شده/ستاره  │
│ • کش در سرویس‌ورکر PWA  │     │ • استریک روزانه مطالعه │
└─────────────────────────┘     └────────────────────────┘
```

1. **تقسیم‌بندی بر اساس سرفصل:** کاربر هنگام باز کردن یک موضوع (مثلاً «کامپیوتر») تنها فایل کوچک همان سرفصل را دانلود می‌کند.
2. **عدم نیاز به سرور دیتابیس دائمی:** هاستینگ به شکل Serverless / Static روی پلتفرم‌هایی چون Vercel یا Cloudflare Pages به صورت کاملاً رایگان انجام می‌پذیرد.

## 🚀 نصب و اجرای پروژه

```bash
# ۱. کلون ریپوزیتوری
git clone https://github.com/TssHack/FarsiMatrix.git
cd FarsiMatrix

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای سرور توسعه
npm run dev
```

آدرس `http://localhost:3000` را در مرورگر باز کنید.

### بیلد پروداکشن:
```bash
npm run build
npm run start
```
